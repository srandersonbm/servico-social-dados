Configuração GitHub

Como configurar:
1. No GitHub, vá em Settings → Developer Settings → Personal Access Tokens → Tokens (classic)
2. Clique em Generate new token (classic)
3. Marque apenas a permissão repo
4. Copie o token gerado e cole abaixo
5. Informe seu usuário GitHub e o nome de um repositório (pode ser privado)
O token é salvo apenas neste navegador (localStorage). Nunca compartilhe este arquivo com o token preenchido.
